Auto7z 6.1.0：繁體中文介面、Apple 簡潔進度條、解壓可靠性與啟動優化，並首次提供獨立 C++ 版本。

### 下載選擇

- **Auto7z-v6.1.0-Windows-x64-Single.exe**：Python 單一 EXE，內附 7-Zip，不需 Python；啟動會解開內嵌依賴。
- **Auto7z-v6.1.0-Windows-x64-Portable.zip**：Python 資料夾版，解壓後執行 Auto7z.exe，保留 _internal，適合重視啟動速度。
- **Auto7zCpp-v6.1.0-Windows-x64-Portable.zip**：C++／Qt6 獨立可攜版，不需 Python，保留同級 DLL 及 plugins；頁面功能與操作分組相同，原生控件細節不同。
- **SHA256SUMS.txt**：下載校驗碼；Source code ZIP／tar.gz 為 GitHub 自動產生的原始碼。

適用 Windows 10／11 x64。請解壓到可寫入目錄，設定不儲存 Password。只附 7-Zip；WinRAR 需自行合法安裝。GPL v3 原始碼、第三方授權與重建方式均在專案內提供。

### 改善

- 大檔解壓不限總時長，可取消，預設關閉停滯保護。
- 修正多層深度、原包保留、密碼輪詢、結果保留、聯動重試與衝突目錄。
- 主介面移除預覽與樣式選擇，固定 Apple 細藍色進度條，數值直接更新。
- 非預設頁延遲建立、短任務立即喚醒、無密碼省略額外預檢、精簡打包依賴。
- 本機原始碼首幀五次中位數約改善 15%；不是所有電腦或解壓時間的保證。

### 驗證與限制

Python 21 項測試；C++ 核心 5 項、介面 2 項與實際引擎相容性 6 組測試。發布檔以內附引擎驗證啟動、中文路徑、解壓與關閉。未完成數十 GB 真實檔案壓力測試，未使用商業程式碼簽章。
